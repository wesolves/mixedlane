A FEW THINGS YOU MIGHT BE WONDERING

Good questions.
Clear answers.

What is Mixedlane?

Mixedlane is a project and issue tracker for software teams, with Kanban boards, a hierarchical work list, shared docs, GitHub automation, and AI agent access through MCP.

Can I use Mixedlane as a Jira alternative?

If your team needs issue tracking, configurable workflows, linked docs, and AI agent access, Mixedlane is worth evaluating. Check your own requirements before switching; migration tooling and feature parity with Jira are not promised.

How do AI agents connect to Mixedlane?

Compatible clients connect to the MCP server. An administrator configures the agent’s project access and permissions, and the agent can then use the tools it is allowed to access. See the MCP setup guide for configuration details.

Can I self-host Mixedlane?

Yes. The repository includes Docker deployment options and PostgreSQL support. Your team manages hosting, backups, email delivery, and updates. Review the deployment guide before setting up a public instance.

Are project docs public?

The marketing homepage is public. Workspace projects, docs, and uploads remain subject to organization membership and access permissions. Creating a landing page does not make your workspace content public.

How do I get started?

Create an account and workspace, start a project, choose your work item types and statuses, and invite your team. Already have a workspace? Sign in here.
